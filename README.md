## Data Pipeline de Vendas + Previsão de Receita com Databricks
---
🧩 Objetivo Geral
Construir um pipeline que:
1. Ingesta dados brutos de vendas e produtos (CSV/JSON)
2. Processa, limpa e transforma os dados com Spark (no Databricks)
3. Cria uma camada analítica em formato Delta Lake
4. Gera insights via SQL + visualizações em notebook
5. Treina um modelo de Machine Learning para prever receita futura

🔧 Tecnologias e Ferramentas
- Databricks Community Edition
- Apache Spark (via PySpark)
- Delta Lake (formato otimizado de armazenamento)
- MLlib (machine learning com Spark)
- SQL no Databricks para análise e visualização
- GitHub para versionamento
